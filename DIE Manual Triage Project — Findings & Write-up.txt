Clean = no packer/compression flagged. Packed = DIE heuristic hit (Packer: Generic [PE in resources]) + compression listed. Matters because packing hides real malware logic : flagged files get escalated to sandbox/manual unpacking instead of static analysis, since packing is itself a red flag. DIE only catches known signatures, so unknown packers need entropy analysis (>7.0), behavioral sandboxing, or post-execution memory dumps instead.
